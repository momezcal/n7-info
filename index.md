# N7

N7 is a personal automation used by its owner to back up files and retrieve selected Google Drive documents for a private local knowledge index. It uses rclone and Google OAuth.

Only the owner operates this automation. This informational website provides no sign-in, file browser, chat, or access to the private system.

Google Drive access is granted separately through Google's consent screen. The requested Drive permission supports listing, reading, creating, and updating files for the owner's configured workflows; it also permits deletion. Publishing this information does not share any Drive files.

See the [privacy notice](privacy.html) for details.
