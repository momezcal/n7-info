# Privacy notice

Last updated: 2026-10-18

## Purpose and data access

N7 is operated by its owner for personal file backups and retrieval of selected Google Drive documents into a private local knowledge index. Google OAuth authorizes rclone to access the owner's Drive. The full Drive permission allows reading, creating, modifying, and deleting files; actual operations depend on the configured workflow.

The knowledge-index workflow reads configured source folders and stores downloaded documents and derived text on the owner's computer. Backup workflows upload the files selected by the owner to Google Drive. This site does not upload, display, or provide access to those documents, OAuth tokens, or the private knowledge index.

## Private processing and access control

Downloaded material can be used by the owner's private tools. Any subsequent use with an AI service is a separate owner-directed workflow governed by that service's settings and terms; this notice does not claim that all processing remains on the computer. The automation does not offer a public account or document-sharing service.

OAuth credentials and tokens are stored separately from this website and its public source files. The owner can revoke the application's access in their Google Account settings. Revocation prevents future authorized access but does not automatically delete previously downloaded copies or backups.

## This informational website

These static pages contain no analytics scripts, forms, advertising, or application login. If hosted on GitHub Pages, GitHub processes website requests under its own [privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Hosting logs are separate from the private Drive automation.
